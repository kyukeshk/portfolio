Build a premium, highly interactive SINGLE-PAGE portfolio website for a
professional Video Editor / Motion Designer / Graphic Designer.

IMPORTANT:

This is NOT a dashboard.
This is NOT a SaaS application.
This is NOT a traditional resume website.

This is a visual storytelling website where the visitor scrolls through
the editor's story and gradually discovers:

1. Who the editor is
2. What he does
3. His experience and expertise
4. The software/tools he uses
5. The type of content he creates
6. His creative work
7. His best reels and videos
8. His graphic design work
9. How to contact him

The entire experience should feel like an interactive digital portfolio
created by a creative professional.

--------------------------------------------------
TECHNOLOGY
--------------------------------------------------

Use:

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP where necessary
- Lenis for smooth scrolling

NO BACKEND.

NO DATABASE.

NO API.

NO AUTHENTICATION.

NO SERVER-SIDE DATA.

Everything must be handled using static local data.

All portfolio information should be easy to modify from local files.

Example:

src/
  assets/
    images/
    videos/
  data/
    projects.ts
    skills.ts
    software.ts
  components/
  sections/

The website must run entirely as a static frontend.

--------------------------------------------------
CORE DESIGN IDEA
--------------------------------------------------

The entire website should feel like one continuous visual journey.

Do NOT make every section look like a separate website section.

The sections should visually flow into one another.

The user should feel:

"First I meet the editor,
then I learn who he is,
then I understand what he does,
then I discover his creative work."

The website should have strong visual continuity.

ANIMATION SYSTEM
--------------------------------------------------

The website should contain lots of animation,
but animation must never make the site difficult to use.

Use:

- Scroll reveal
- Text splitting
- Mask reveals
- Image reveals
- Parallax
- Magnetic buttons
- Cursor interactions
- Hover previews
- Video hover effects
- Number counters
- Horizontal scrolling
- Clip-path transitions
- Scale transitions
- Smooth page loading
- Section transitions

Use spring-like or smooth easing.

Avoid:

- Constant bouncing
- Excessive spinning
- Random animations
- Too many gradients
- Overly aggressive parallax

The website should feel:

SMOOTH
PREMIUM
CINEMATIC
CONTROLLED

--------------------------------------------------
RESPONSIVE DESIGN
--------------------------------------------------

Desktop:

Large editorial layouts
Custom cursor
Large typography
Complex animations

Tablet:

Simplified layouts
Reduced animation complexity

Mobile:

Single column
Touch-friendly interactions
No custom cursor
Vertical video layouts
Horizontal category navigation
Reduced parallax

Do not simply shrink desktop.

Design mobile intentionally.

--------------------------------------------------
PERFORMANCE
--------------------------------------------------

This portfolio will contain many images and videos.

Performance is extremely important.

Implement:

- Lazy loading images
- Lazy loading videos
- IntersectionObserver
- Poster images
- Responsive image sizes
- Compressed videos
- WebM where possible
- MP4 fallback
- Only preload hero video/image
- Pause off-screen videos
- Avoid loading every video on initial page load

Do not allow animations to cause scrolling lag.

Respect:

prefers-reduced-motion

and reduce animation for users who request reduced motion.

--------------------------------------------------
LOCAL DATA ARCHITECTURE
--------------------------------------------------

Because there is NO backend,
all content should come from local TypeScript data.

Example:

projects.ts

export const projects = [
  {
    id: 1,
    title: "Project Name",
    category: "Social Media Reel",
    year: "2026",
    type: "video",
    thumbnail: "/assets/images/project-01.webp",
    video: "/assets/videos/project-01.mp4",
    role: "Video Editing / Color Grading"
  }
]

Create similar data structures for:

software.ts
skills.ts
categories.ts

This makes the portfolio easy to maintain.
